# E-PROM

**Express Fuzzy Preference Ranking with PROMETHEE**

E-PROM integrates FAHP-Express for fuzzy criteria weighting with Fuzzy PROMETHEE for multicriteria alternative ranking.

## Included files

- `app.py` — Streamlit application
- `core/` — application core modules; copy the existing project `core/` folder here
- `templates/E_PROM_Avaliacoes_Modelo.xlsx` — evaluation template
- `templates/E_PROM_FAHP_Express_Modelo.xlsx` — FAHP-Express template
- `E_PROM_Guide.pdf` — user guide
- `requirements.txt` — Python dependencies

## Deployment

On Streamlit Community Cloud, set `app.py` as the main file. The `core/` directory must be in the same repository level as `app.py`.
